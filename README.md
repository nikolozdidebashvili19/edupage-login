# EduPage Sign-In Design Preview

A React and Vite frontend recreation of the provided EduPage sign-in screen references.

This is a visual-only mockup. It is not affiliated with or connected to EduPage, does not authenticate users, and does not collect, store, or send account details. The example fields are read-only, and the mobile-login illustration is decorative rather than a QR code.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.
